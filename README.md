# 🩺 Insurance Cost Prediction

## 📘 Overview
This project explores **insurance cost prediction** using **Exploratory Data Analysis (EDA)** and **Linear Regression**. The goal is to understand how factors like age, gender, BMI, smoking habits, and region influence medical insurance charges.

It’s part of the *Machine Learning from Sheryians AI* series, focusing on building foundational data science skills through hands-on projects.

---

## 🧠 Objectives
- Perform EDA to uncover relationships between variables.
- Clean and preprocess the dataset.
- Build a linear regression model to predict insurance costs.
- Evaluate model performance using metrics like R² and MSE.

---

## 🛠️ Technologies Used
- Python 3.x  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Scikit-learn
